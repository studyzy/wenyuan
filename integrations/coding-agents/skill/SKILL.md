# wenyuan-memory

A placeholder for the packaged companion skill.

The installer copies this directory into each host's skills directory and
removes exactly that copy on uninstall. The skill's substance, structure and
front matter belong to a later slice; what is fixed here is only that the copy
and the removal happen, and that they are keyed by this directory.
